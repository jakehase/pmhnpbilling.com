# PMHNP Billing — quiet warm homepage concept

Preview-only concept created from Jake's 2026-07-16 direction: move beyond a merely warmer corporate layout toward a genuinely human, professional site without becoming cute or whimsical.

## Current direction

- Uses a warm, patient-free workspace photograph instead of a SaaS dashboard, personal portrait, letter card, or product mockup.
- Removes the metric strip, dark support cards, numbered process framework, pill CTAs, and most boxed layout cues.
- Leads with conversational language and generous editorial spacing.
- Uses deep warm green, muted clay, sage, cream, natural wood, and subtle paper texture.
- Keeps credibility through direct service descriptions, clear pricing, and accountable working-language rather than corporate UI patterns.

## Motion preserved

- 4.5% logo hover/focus growth.
- 7.2-second logo breathing.
- 8.5/10-second dual hero accent breathing.
- Scroll-triggered reveals and subtle image parallax.
- Pointer tilt and restrained hover movement.
- Complete `prefers-reduced-motion` shutdown.

## Image

`assets/warm-workspace-hero.jpg` is an AI-generated, patient-free editorial workspace image created for this design concept. It contains no logos, readable documents, patient information, or medical records.

## Boundary

This published path is a `noindex, nofollow` preview. It does not replace the production homepage, SEO/schema, navigation, forms, analytics, or accessibility behavior until explicitly approved.
